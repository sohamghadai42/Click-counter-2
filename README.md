# Click Counter

A simple click counter web application built with vanilla JavaScript to practice fundamental web development concepts.

## Features

- ➕ Increment counter
- ➖ Decrement counter
- 🔄 Reset counter to zero
- Clean and responsive UI

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

## What I Learned

This project helped me practice:
- DOM manipulation and element selection
- Event listeners and handling user interactions
- Updating the UI dynamically based on state
- Basic JavaScript logic and functions

## Installation

1. Clone the repository:
```bash
git clone https://github.com/sohamghadai42/Click-counter-2.git
```

2. Navigate to the project directory:
```bash
cd click-counter
```

3. Open `index.html` in your browser or use a live server.

## Usage

- Click the ** + ** button to increase the counter
- Click the ** - ** button to decrease the counter
- Click the **Reset** button to set the counter back to zero
